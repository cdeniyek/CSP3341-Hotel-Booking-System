# CSP3341 – Hotel Room Booking System

This project is a console-based Hotel Room Booking System developed using C++20
as part of the CSP3341 – Programming Languages and Paradigms unit.

## Features
- Add and list hotel rooms
- Check-in and check-out operations
- File persistence using CSV files
- Object-oriented design (Room, Booking, HotelManager)

## Development Environment
- Language: C++20
- IDE: Microsoft Visual Studio 2022

## How to Run
1. Open the project in Visual Studio 2022
2. Build the solution
3. Run the application from the console
